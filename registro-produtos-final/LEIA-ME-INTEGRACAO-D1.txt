INTEGRACAO CLOUDFLARE D1 — REGISTRO DE PRODUTOS

Arquivos incluídos:
- lancamento.html: consulta cada EAN diretamente no Worker/D1; não depende de produtos_ean.json.
- painelconferente.html: mantém as funções atuais do painel e grava novos produtos no D1 via Apps Script.
- code.gs: substitui a gravação do catálogo no GitHub por POST autenticado ao Worker.
- catalogo-sqlite.js: mantém a interface CatalogoSQLite usada pelo painel, mas lê o catálogo do Worker/D1.

IMPORTANTE — CONFIGURAÇÃO SEGURA
1. No projeto Apps Script, abra Configurações do projeto > Propriedades do script.
2. Crie D1_WORKER_URL = https://registro-produtos-api.luisarthurofficial.workers.dev
3. Crie D1_API_SECRET com o mesmo valor configurado como secret API_SECRET no Cloudflare Worker.
4. Não coloque D1_API_SECRET em HTML, GitHub Pages, repositório público ou arquivo JavaScript do navegador.
5. Confirme que o Worker continua com binding D1 chamado DB e CORS permitindo https://luisarthurdev.github.io.

PUBLICAÇÃO
- Substitua no GitHub Pages os arquivos lancamento.html, painelconferente.html e catalogo-sqlite.js pelos deste pacote.
- Atualize o projeto Apps Script com o code.gs completo deste pacote e publique/atualize a implantação do Web App conforme o procedimento já usado no projeto.
- Mantenha os demais arquivos atuais do repositório (index.html, auth.js, notificacoes.js, login.gs, etc.).

OBSERVAÇÃO
O catálogo do painel é carregado via paginação (até 5.000 produtos por requisição) para preservar as funções síncronas de busca/relacionamento existentes. O lançamento individual consulta apenas o EAN informado.
